# NSU-net-autologin

成都东软学院 WebCC 校园网自动登录工具，适用于 Windows 10/11 x64。使用原生 C 编写的 EXE 图形界面配置账号、连接校园网和注册自启，无需运行 CMD。

本项目为非官方工具，当前版本为 v1.3，仅适配 `2.2.2.2/Auth.ashx`。

> [!IMPORTANT]
> 本工具已知会被360报毒！！！项目由GPT-6-Astra基于C语言编写，要正常使用请将该EXE加入白名单，实在不放心可以自己审查源代码并编译或者放弃使用

## 开始使用

1. 在 [Release 下载 v1.3](https://github.com/L1Xu4n/NSU-net-autologin/releases/tag/v1.3) 的 `NSU-Net-Autologin.exe`。
2. 使用网线或 WIFI 连接“NSU-SDN”，双击主程序。
3. 点击底部「配置账号」，填写校园网账号、密码并选择运营商。
4. 在主界面选择「网线」或「Wi-Fi」，点击「上线」。未连接的网卡不可选。
5. 按需点击「注册开机自启」，让登录及休眠后解锁时自动连接。

EXE 使用 Win32、Winsock、IP Helper、CryptoAPI/DPAPI 和任务调度器 COM 接口，不嵌入或调用 PowerShell，不依赖 .NET。v1.0 的原生账号配置可继续使用。主窗口读取实际自启状态：已经注册时，底部按钮显示「卸载自启动」；无法确认状态时提示重新检查，不把读取失败当成未注册。

原生实现不能保证所有杀毒软件都不误报。本地测试副本被 360 以 `HEUR/QVM202.0.05B9.Malware.Gen` 拦截，目前原因尚未得到厂商确认；当前产物没有代码签名，不能宣称已通过杀毒检测。

注册自启后请保留主 EXE 的位置；升级时，先点击「卸载自启动」并选择保留配置，退出旧程序，再用 v1.3 重新注册，以更新程序路径及常驻任务设置。关闭主界面后程序留在托盘，继续检测网线；右键托盘图标可打开主窗口或退出。

## 配置与重连

主窗口右上角的「关于」显示作者与项目仓库地址，可复制地址或点击「打开 GitHub 仓库」访问。

主界面分别显示 Wi-Fi 和网线的物理连接状态、IPv4 地址及 MAC。“已连接”表示网卡已就绪，校园网认证结果单独显示在按钮下方。双连接时可主动选择任一网卡，上线时先下线另一网卡中精确匹配本机 IP/MAC 的旧会话，再为所选网卡上线。

Wi-Fi 和网线各有独立图标。“校园网”一栏显示已上线的网卡、未上线、状态待确认或需要电话验证。正常情况下约每二十秒查询一次当前账号会话，也可点击「刷新」；查询本身不会开通网络或下线设备。查询失败后暂停自动查询，避免反复提交失败的认证，可手动刷新或在网卡变化后重新检查。托盘悬停同步显示校园网状态，主动下线时附带“自动重连已暂停”。

点击「下线」只处理所选网卡的本机会话，并在确认下线后显示结果。主动下线会暂停本次运行的自动重连，插拔网线或解锁也不会立即重新上线；再次点击「上线」恢复。手动打开主界面时可先选择网卡再上线；开机自启保留自动连接。N 形网络节点 Logo 已嵌入窗口、托盘和 EXE。

开机自动启动后，程序在托盘等待可用网卡。每次连接操作会先显示检查进度；入口无法访问时最多等待约三分钟，超时后显示失败提示。关闭提示不会停止后台检测。账号尚未配置时显示主窗口，引导配置账号。

连接校园网时默认使用网线网卡的 MAC；Wi-Fi 已连接后插入网线，约两秒内检测到可用有线 IPv4 地址后开始切换。请求固定从所选网卡发出，不修改系统 MAC 或路由。切换前先核对校园网返回的 IP/MAC，再只下线与本机 Wi-Fi IP 和 MAC 同时匹配的会话，确认下线后通过有线重新上线；下线失败或要求验证时停止。

开机自动连接时，若 Wi-Fi 和网线都已取得可用 IPv4 地址，会弹出网卡选择框，十秒后默认使用网线 MAC。选择 Wi-Fi 后，在本次运行中保留选择，直到网线发生插拔/地址变化或 Wi-Fi 断开；关闭选择框也默认使用网线。多张同类物理网卡取接口跃点数较小者，排除虚拟网卡。

修改配置时，原账号的密码留空表示保留；更换账号必须填写新密码。取消窗口不会更改原设置。同一运营商有多个套餐时，填写网页显示的完整套餐名，例如 `学生-移动-200M`；没有匹配或多个匹配时程序会停止。

程序常驻期间检测网卡变化，并在 Windows 解锁或从休眠恢复后检查连接。已经通过选定网卡在线则保留连接，掉线才重连。验证或账号错误不会按两秒周期反复提交；处理后点击「上线」。程序不主动唤醒电脑。

手动连接及自动重连完成后，会在右下角任务栏上方显示不抢焦点的提示，约八秒后关闭；成功文字为绿色，失败或需要处理的文字为红色。只有接口确认所选网卡的 IP/MAC 已上线，才提示成功。如果学校要求电话验证，会停止自动操作，显示保留两分钟的提醒，并提取提示中“拨打 / 致电”等指令后的号码；号码缺失或无法识别时明确提示到网页查看。点击「打开验证网页」，按学校要求完成验证，再点击「上线」。号码仅显示在界面，不写入日志；程序不自动拨号或设置常用设备。

提示窗口与所在显示器的任务栏可用区域底部保留 64 个逻辑像素，随 DPI 缩放，减少遮挡。离线状态下校园网返回空 MAC 属于正常情况；程序会先确认 IP 一致且在线列表中没有本机，再允许后续上线，真实的 IP/MAC 不匹配仍会停止操作。

## 卸载

不再需要独立卸载程序。在主窗口点击「卸载自启动」，弹窗询问是否同时删除账号配置：选择「是」删除新旧两份账号配置，选择「否」保留配置，选择「取消」不做修改。默认焦点在保留配置的选项上。

卸载会检查计划任务和旧版启动快捷方式是否已经移除；原本不存在或重复卸载也算完成。成功后按钮恢复「注册开机自启」。删除配置时也检查文件是否消失，权限不足会明确提示。运行日志保留；不再使用时可关闭窗口后删除主 EXE。

## 密码和日志

个人配置保存在 `%LOCALAPPDATA%\CampusNetworkLogin\config.native`，整份记录通过 Windows DPAPI 加密，仅当前 Windows 用户可解密。旧版 `config.clixml` 保留。不要上传或分享私人配置文件。

日志位于 `%LOCALAPPDATA%\CampusNetworkLogin\CampusLogin.log`，不记录账号、密码、密码编码、Cookie 或接口完整响应；约 1 MB 时轮转并保留一份旧日志。

程序使用学校现有的 HTTP 接口及网页相同的 DES 编码，编码不能替代 HTTPS。仅在切换有线时下线精确匹配的本机 Wi-Fi 会话，不主动下线其他设备、修改密码或购买套餐。设备数量上限或电话验证需用户处理。

## 验证范围

- 原生自测覆盖 JSON、登录与设备切换模拟、电话验证中断、套餐、DES、隔离 DPAPI 配置及重复删除。任务生命周期测试创建禁用的 GUID 临时任务，核验注册、查询、卸载与再次卸载，最后清理；不改变正式自启项。
- 注册改用 Windows 原生强类型任务接口；回读启用状态、EXE 路径、--startup 参数以及登录/解锁触发器后才提示成功。失败时显示阶段和错误码。修复版已在本机成功注册正式自启任务。
- 修复版的独立目录测试通过，包含协议/DES/DPAPI、临时任务注册/重复注册/卸载/再次卸载、正式任务保持不变、100%/150% 界面。之前的 360 告警仍作为历史问题保留，单次功能测试通过不等于厂商确认安全。
- 真实离线登录、套餐开通、电话验证、重启和休眠后重连的完整流程仍待实测。模拟测试不代表真实校园网全流程已验证。
- v1.1 增加有线切换顺序、下线失败/验证中断、MAC 不符停止、号码提取、HTTP 分帧/Cookie 和十秒选择验证；本机真实只读 Check 通过。真实网线插拔切换和学校电话验证响应仍待现场验证。
- v1.2 增加主动下线的目标核验/结果确认、有线切换 Wi-Fi、主界面选择及暂停自动重连验证；布局覆盖 100%/150% 缩放。验证不调用真实账号的上线或下线接口。

## 开发与打包

旧版登录脚本、CMD 入口和旧测试已移除；仓库仅保留原生 C 实现，正式 ZIP 仅包含主 EXE。开发电脑需要 Visual Studio Build Tools 的「使用 C++ 的桌面开发」组件；以下 PowerShell 命令只用于构建和测试，用户运行 EXE 不需要执行脚本：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\Build-Release.ps1
powershell.exe -NoProfile -STA -ExecutionPolicy Bypass -File .\tests\Test-Exe.ps1
```

`Build-Exe.ps1` 使用 MSVC 的 C 编译模式生成原生 x64 主程序，静态链接 C 运行库，嵌入原生控件清单及图标，不加壳或混淆。`Build-Release.ps1` 默认生成 `dist/v1.3/` 下的 EXE、ZIP 和 SHA256；可用 `-OutputDirectory` 指定目录。产物为 `dist/v1.3/NSU-Net-Autologin.exe`、`NSU-net-autologin-v1.3.zip` 和对应 `.sha256`。注册后请保留程序位置。测试不修改真实账号或正式自启任务。

Logo 源资产位于 `app/assets/`，包含 SVG、PNG 和多尺寸 ICO；运行 `scripts/Build-Icon.ps1` 可重新生成，正常构建直接使用已保存的 ICO。

主 EXE 支持 `--check-only` 只读检查接口；计划任务使用 `--startup`。维护时可明确使用 `--install` 调用与按钮相同的注册流程，需要先配置账号，不会发起校园网登录。普通用户使用主窗口即可。函数及方法说明见 [docs/FUNCTIONS.md](docs/FUNCTIONS.md)。
