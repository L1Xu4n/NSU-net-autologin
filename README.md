# NSU-net-autologin

成都东软学院 WebCC 校园网自动登录工具，适用于 Windows 10/11 x64。使用原生 C 编写的 EXE 图形界面配置账号、连接校园网和注册自启，无需运行 CMD。

本项目为非官方工具，当前正式版为 v1.0，仅适配 `2.2.2.2/Auth.ashx`。

> 本工具已知会被360报毒！！！项目由GPT-6-Astra基于C语言编写，要正常使用请将该EXE加入白名单，实在不放心可以自己审查源代码并编译或者放弃使用

## 开始使用

1. 在Release[下载](https://github.com/L1Xu4n/NSU-net-autologin/releases/tag/v1.0) `NSU-Net-Autologin.exe`。
2. 使用网线或 WIFI 连接“NSU-SDN”，双击主程序。
3. 点击最上方「配置账号」，填写校园网账号、密码并选择运营商。
4. 点击中间的「注册开机自启」，让登录及休眠后解锁时自动连接。自启为可选功能；账号尚未配置时会先引导配置。
5. 点击下方「立即连接」。

EXE 使用 Win32、WinHTTP、CryptoAPI/DPAPI 和任务调度器 COM 接口，不嵌入或调用 PowerShell，不依赖 .NET。原生版首次需要重新填写配置；旧版配置保留，不自动迁移。主窗口读取实际自启状态：已经注册时，中间按钮显示「卸载自启动」；无法确认状态时提示重新检查，不把读取失败当成未注册。

原生实现不能保证所有杀毒软件都不误报。本地测试副本被 360 以 `HEUR/QVM202.0.05B9.Malware.Gen` 拦截，目前原因尚未得到厂商确认；当前产物没有代码签名，不能宣称已通过杀毒检测。

注册自启后请保留主 EXE 的位置；移动文件或从旧版升级时，先点击「卸载自启动」并选择保留配置，再在新位置重新注册。关闭主界面不影响已注册的自动连接。

## 配置与重连

主窗口右上角的「关于」显示作者与项目仓库地址，可复制地址或点击「打开 GitHub 仓库」访问。

手动连接或自动启动时先显示检查进度；入口无法访问时，右下角显示蓝色“正在等待 Wi-Fi 或网线连接后自动登录”提示。等待期间提示持续可见，关闭提示不会取消后台等待，也不会每次重试都重新弹窗。连接 NSU-SDN 网络后自动继续登录；最多等待约三分钟，超时后显示失败提示。账号尚未配置时会先提示配置账号。

修改配置时，原账号的密码留空表示保留；更换账号必须填写新密码。取消窗口不会更改原设置。同一运营商有多个套餐时，填写网页显示的完整套餐名，例如 `学生-移动-200M`；没有匹配或多个匹配时程序会停止。

自动任务在登录或解锁 Windows 时检查网络。已经在线则结束，掉线才重连，无需等待满五分钟。普通锁屏后解锁也会检查；唤醒后没有解锁事件、直接恢复桌面时不会触发，可点击「立即连接」。程序不主动唤醒电脑。

网络尚未就绪时等待最多约三分钟。手动连接及自动重连完成后，会在右下角任务栏上方显示不抢焦点的提示，约八秒后关闭；成功文字为绿色，失败或需要处理的文字为红色。只有接口确认本机 IP 已上线，才提示登录成功。如果学校要求电话验证，会停止自动操作，显示保留两分钟的提醒；点击「打开验证网页」，按学校网页要求完成验证，再点击「立即连接」。建议在校园网网页中将本机设为常用设备，以减少后续电话验证。提示窗口根据文字高度计算大小，确保按钮完整显示；程序不自动拨号、填写验证码或设置常用设备。

## 卸载

不再需要独立卸载程序。在主窗口点击「卸载自启动」，弹窗询问是否同时删除账号配置：选择「是」删除新旧两份账号配置，选择「否」保留配置，选择「取消」不做修改。默认焦点在保留配置的选项上。

卸载会检查计划任务和旧版启动快捷方式是否已经移除；原本不存在或重复卸载也算完成。成功后按钮恢复「注册开机自启」。删除配置时也检查文件是否消失，权限不足会明确提示。运行日志保留；不再使用时可关闭窗口后删除主 EXE。

## 密码和日志

个人配置保存在 `%LOCALAPPDATA%\CampusNetworkLogin\config.native`，整份记录通过 Windows DPAPI 加密，仅当前 Windows 用户可解密。旧版 `config.clixml` 保留。不要上传或分享私人配置文件。

日志位于 `%LOCALAPPDATA%\CampusNetworkLogin\CampusLogin.log`，不记录账号、密码、密码编码、Cookie 或接口完整响应；约 1 MB 时轮转并保留一份旧日志。

程序使用学校现有的 HTTP 接口及网页相同的 DES 编码，编码不能替代 HTTPS。程序不会主动下线其他设备、修改密码、购买套餐或反复提交错误密码。设备数量上限或电话验证需用户处理。

## 开发与打包

旧版登录脚本、CMD 入口和旧测试已移除；仓库仅保留原生 C 实现，正式 ZIP 仅包含主 EXE。开发电脑需要 Visual Studio Build Tools 的「使用 C++ 的桌面开发」组件；以下 PowerShell 命令只用于构建和测试，用户运行 EXE 不需要执行脚本：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\Build-Release.ps1
powershell.exe -NoProfile -STA -ExecutionPolicy Bypass -File .\tests\Test-Exe.ps1
```

`Build-Exe.ps1` 使用 MSVC 的 C 编译模式生成原生 x64 主程序，静态链接 C 运行库，不加壳或混淆。`Build-Release.ps1` 默认生成 `dist/v1.0/` 下的 EXE、ZIP 和 SHA256；可用 `-OutputDirectory` 指定目录。正式产物为 `dist/v1.0/NSU-Net-Autologin.exe`、`NSU-net-autologin-v1.0.zip` 和对应 `.sha256`。注册后请保留程序位置。测试不修改真实账号或正式自启任务。

主 EXE 支持 `--check-only` 只读检查接口；计划任务使用 `--startup`。维护时可明确使用 `--install` 调用与按钮相同的注册流程，需要先配置账号，不会发起校园网登录。普通用户使用主窗口即可。函数及方法说明见 [docs/FUNCTIONS.md](docs/FUNCTIONS.md)。
